# OMORIgallery
Developed and launched the OMORI Photo Album, an interactive web-based gallery showcasing
fan art inspired by the indie game OMORI, using HTML/CSS and JavaScript
Collaborated with 50+ artists across the world to curate and display their artwork

Open the ```OMORI_GALLERY.html``` file
